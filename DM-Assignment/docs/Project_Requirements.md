## 🎯 任务描述

### 核心任务

训练二分类器，预测测试数据标签(0 或 1)，目标是最大化测试集 F1 Score

### 数据规格

**训练集 (train.csv)**

```
样本数: 10,853
特征数: 43
├── 数值特征: 25个 (Num_Col1~25)
├── 类别特征: 18个 (Nom_Col26~43, 格式: Cx_cN)
└── 标签: Target (0或1, 1为正类)
缺失值: NaN
```

**测试集 (test_data.csv)**

```
样本数: 2,713
特征数: 43 (与训练集相同)
标签: 不提供
```

## 📊 评分标准

### 前置条件 (必须全部满足)

1. ✅ 预处理和模型选择可复现
2. ✅ 分类器可复现
3. ✅ 仅使用 Week 2-8 技术

5. ✅ 结果由实际训练的模型生成

**不满足任一条件 → 0 分**

### F1 分数到成绩的映射

| F1 Score  | Mark                 | 说明           |
| --------- | -------------------- | -------------- |
| ≤ 0.50    | 0                    | 不及格         |
| 0.50-0.60 | 每 0.01 → 1 分       | 例: 0.55→5 分  |
| 0.60-0.65 | 10 + 每 0.005 → 1 分 | 例: 0.63→16 分 |
| ≥ 0.65    | 20                   | 满分           |

**关键阈值**:

- F1 ≥ 0.60 → 及格 (10 分)
- F1 ≥ 0.65 → 满分 (20 分)

## 🚨 常见失分原因

### 文件相关

- [ ] 文件命名错误 (大小写、缺少 s、额外字符)
- [ ] Turnitin 标题与文件名不一致
- [ ] Python 提交.ipynb 而非.py 文件

### 格式相关

- [ ] 结果文件行数不对 (不是 2714 行)
- [ ] 预测值格式错误 (不是整数或缺少逗号)
- [ ] CV 分数格式错误 (不是 3 位小数或缺少逗号)

### 代码相关

- [ ] 随机种子未固定
- [ ] 缺少 main.py 入口文件
- [ ] 代码不可复现
- [ ] 缺少 train.csv 或 test_data.csv

### 技术相关

- [ ] 使用了禁止的技术
- [ ] 无法从代码复现结果
